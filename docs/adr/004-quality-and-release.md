# ADR-004 — Coverage en releaseprovenance

Status: Accepted. Requirements: CH-TEST-001..004, CH-DIST-001..006.

Projectgemiddelde is onvoldoende; ieder eigen uitvoerbaar bestand moet strikt boven 80% zitten en ontbrekende bestanden falen. Releaseassets verwijzen naar een exacte broncommit en externe hashes; een evidencecommit kan later bewijs toevoegen zonder zichzelf in de eerdere wheel te verankeren. Bestaande versies/assets worden nooit vervangen.
