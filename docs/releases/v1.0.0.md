# Company Harvest 1.0.0

Een lokale, auditbare CLI voor het verzamelen en samenvoegen van Nederlandse
organisatiegegevens. Deze versie bevat:

- Zelfstandige vierbronnenvoorbereiding uit IND, GLEIF, ANBI en DUO;
  Wikidata is uitgesloten van deze workflow.
- Verliesvrije pre-KVK-master, herleidbare deduplicatie en een afzonderlijke
  toelatingsfilter met criteria, uitsluitingsledger, hashes en count-closure.
- Een kleine batchroute en een expliciet hervatbare langlopende route via de
  publieke KVK-frontend-Web-API (niet de officiële API-key-route). De lange
  route gebruikt minimaal twee seconden tussen verzoekstarts, één pagina en
  één poging per kandidaat, duurzaam journal en lokale voortgangsbestanden.
- Offline lijstmerge, lokale audits en CSV-/XLSX-export met expliciete
  unresolved-/partial-poorten.

De tool start geen harvest bij installatie of openen. Een volledige
KVK-doorloop van de huidige 119.801 gefilterde kandidaten is **niet**
uitgevoerd of als schaal-/gebruiksrechtelijk geschikt bewezen. Een lokale
rooktest van één aanroep eindigde met `NETWORK_ERROR`; de openbare route is
voor deze versie dus niet live als volledige workflow aangetoond. `COMPLETE`
in de KVK-run betekent een gesloten kandidaatpartitie, niet dat alle
organisaties een bevestigde match hebben. Een lijst van 10.000 unieke,
actieve ondernemingen is nog niet opgeleverd. Beoordeel de voorwaarden voor
grootschalig gebruik van Handelsregistergegevens afzonderlijk.

De actieve CI-matrix is Python 3.14 op macOS en Windows. De package accepteert
CPython 3.11–3.14, maar voor de wijzigingen sinds 0.1.0 zijn Linux en
Python 3.11–3.13 niet doorlopend in CI gevalideerd. Playwright Chromium
vereist een afzonderlijke installatie indien de browserprovider wordt
gebruikt.

Een geïnstalleerde wheel gebruikt geen checkout, Git of GitHub-login.
Kwalificatie- en downloadbewijs worden uitsluitend na daadwerkelijke
publicatie in de repository vastgelegd.
