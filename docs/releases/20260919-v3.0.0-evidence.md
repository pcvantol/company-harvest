## Gefaseerde publicatie en anonieme controle

De directe `tools/release.py publish`-route is **niet** gebruikt, omdat die
de conceptassets niet vóór openbaarmaking terugdownloadt. Na een
succesvolle GitHub-API-read en exclusiviteitscontrole is de tag gepusht en
zijn de vijf assets als conceptrelease geüpload. GitHub gaf `isDraft=true`
en dezelfde namen, groottes en SHA-256-digests. `gh release download`
haalde alle conceptassets terug; `diff -rq` tegen de lokaal gekwalificeerde
set gaf exit 0, net als `tools/release.py verify` op de gedownloade set.

Pas daarna is de [publieke GitHub Release v3.0.0](https://github.com/pcvantol/company-harvest/releases/tag/v3.0.0)
op 2026-09-19 om 18:51:11 UTC vrijgegeven (`isDraft=false`,
`isPrerelease=false`). Alle vijf assets zijn vervolgens via gewone HTTPS
**zonder GitHub-authenticatie** opgehaald; `diff -rq` met de oorspronkelijke
build gaf weer exit 0 en het gedownloade manifest/alle assets slaagden
opnieuw voor hash- en inhoudsscan.

De anoniem gedownloade [wheel](https://github.com/pcvantol/company-harvest/releases/download/v3.0.0/company_harvest-3.0.0-py3-none-any.whl)
is opnieuw geïnstalleerd in een nieuwe macOS/Python-3.14-venv buiten de
checkout, met normale online dependencyinstallatie en zonder GitHub-login.
CLI `--version` meldde `3.0.0`, import kwam uit `site-packages`, `doctor`
gaf `ready=true` en `run e2e --help` toonde de actuele
`--limit-kvk-check | --all-kvk`-interface. De volledige synthetische
workflow-/auditsmoke was al op dezelfde gekwalificeerde bytes uitgevoerd.

## Grenzen

Dit bewijst distributie en offline werking, **niet** een live productieharvest
of een nieuwe publieke KVK-nummerzoekactie. Er zijn voor deze release geen
echte KVK-verzoeken gedaan en geen 10.000 bedrijven geleverd. Actuele
bronbereikbaarheid, KVK-veldsemantiek en grootschalige gebruiksvoorwaarden
blijven open R7/R9-gates. Een afzonderlijke anonieme wheelinstallatie op
Windows is `NOT_TESTED`; de exacte broncommit en offline E2E zijn wel op
Windows/Python 3.14 in CI geslaagd.
