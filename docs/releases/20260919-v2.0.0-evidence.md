## Publicatie en anonieme herdownload

De vijf assets zijn eerst als concept-GitHub Release aangemaakt. GitHub gaf
`draft=true`, vijf correcte namen en groottes. `gh release download` haalde
de conceptassets terug; `diff -rq` tegen de lokale gekwalificeerde map gaf
exit 0 en `tools/release.py verify` controleerde de hashes en scan opnieuw.
Pas daarna is het concept gepubliceerd.

De [publieke GitHub Release v2.0.0](https://github.com/pcvantol/company-harvest/releases/tag/v2.0.0)
is op 2026-09-19 om 16:08:22 UTC teruggelezen als
`draft=false`, `prerelease=false`. Alle vijf assets zijn vervolgens met
gewone HTTPS-verzoeken zonder GitHub-authenticatie opnieuw gedownload;
`diff -rq` met de gekwalificeerde distributiemap gaf opnieuw exit 0.
De GitHub asset-digests en groottes komen met de bovenstaande waarden overeen.
De directe [wheel-download](https://github.com/pcvantol/company-harvest/releases/download/v2.0.0/company_harvest-2.0.0-py3-none-any.whl)
werd vanuit die anonieme download opnieuw in een verse Python-3.14-omgeving
geïnstalleerd: versie `2.0.0`, import uit `site-packages`, synthetische
HARVEST-/MERGE_LISTS-workflows en audit allemaal `PASS`.
De [onafhankelijke postpublicatiereview](../reviews/20260919T161316Z_ch-2026-09-19-028_postpublication-review.md)

niet zelfstandig bereiken.

## Grenzen

Dit kwalificeert de softwaredistributie, niet een live productieharvest. Er
is voor deze publicatie geen publieke KVK-bulkrun gestart, geen 10.000-record
doellijst opgeleverd en geen actuele KVK-capability als `PASS` geclaimd.
`run e2e` kan op externe bron- of KVK-blokkades stoppen; `--all-kvk` is geen
garantie op volledige matching. De officiële KVK-API en Wikidata blijven
buiten deze geïntegreerde workflow. De v2.0.0-wheel ondersteunt uitsluitend
Python 3.14.x; v1.0.0 had een breder Python-contract en blijft ongewijzigd.
