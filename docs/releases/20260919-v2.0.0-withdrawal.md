# Intrekking v2.0.0 — CH-2026-09-19-038

Op expliciet eigenaarsverzoek zijn alle tags en GitHub Releases met een
semantische versie lager dan 3.0 verwijderd. De voorafgaande inventaris
van de volledige GitHub REST-releaselijst (inclusief concepten), `origin`
en lokale tags bevatte alleen `v2.0.0` en `v3.0.0`. **Alleen `v2.0.0` viel
onder de grens.** Er is geen onbekende of hogere versie aangeraakt.

Vóór de ingreep wees de geannoteerde remote v2.0.0-tag naar broncommit
`bb0f894d82db4ee1f709f0065cb0c5e8c368a5d7`; de publieke release
bevatte vijf assets: wheel, sdist, online bundel, checksums en
distributiemanifest. Deze release is zonder automatische tagcleanup
verwijderd. Na controle dat uitsluitend v3.0.0 als release overbleef,
zijn apart `refs/tags/v2.0.0` op `origin` en daarna de lokale tag gewist.

De nacontrole van de volledige REST-releaselijst bevat precies één
publieke, niet-prerelease release: `v3.0.0` met vijf ongewijzigde assets
en digests. Lokale en remote Git-tags bevatten alleen `v3.0.0`, waarvan
de commit `12b861e1c0298afee5396154883c67d8744246aa` is. De oude
v2.0.0-broncommit blijft een voorouder van `main`. Genegeerde lokale
buildkopieën onder `.local/releases/` zijn niet verwijderd; historische
releasenotities en [publicatiebewijs](20260919-v2.0.0-evidence.md)
blijven leesbaar als bewijs van de toenmalige release.

De vijf **publieke** v2.0.0-assets zijn verwijderd; hun oude downloadlinks
werken niet meer. Een anonieme controle van de voormalige directe
wheel-URL gaf HTTP 404. Een reeds lokaal bewaarde wheel of installatie wordt
niet door deze actie gewist. Nieuwe installaties gebruiken uitsluitend
de [v3.0.0-release](https://github.com/pcvantol/company-harvest/releases/tag/v3.0.0).
Er is geen nieuwe software-release, live bron-/KVK-harvest of wijziging
aan pakketversie, rungegevens of v3.0.0-assets uitgevoerd.
