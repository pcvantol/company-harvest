# Verzoek CH-2026-09-19-014

- Ontvangen: 2026-09-19
- Execution ID: `CH-2026-09-19-014`
- Versie-impact: geen; uitsluitend audit van bestaande GitHub Releases

## Verbatim verzoek

> verwijder alle oude releases < 1.0.0

## Bindende interpretatie

Inventariseer alle GitHub Release-objecten, inclusief conceptreleases, en
verwijder uitsluitend bestaande releases met een semantische versie lager dan
`1.0.0`. Verwijder geen Git-tags, commits, lokale builds of andere gegevens:
die vallen niet onder het gevraagde release-object. Verifieer de toestand na
de actie; als er geen doelobjecten zijn, voer geen destructieve call uit.
