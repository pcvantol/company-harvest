## Verbatim verzoek

> zorg dat tool alleen python 3.14 werkt

## Interpretatie

De actuele tool accepteert en start uitsluitend Python 3.14.x. Andere
minorversies worden door wheelmetadata geweigerd en krijgen ook bij een
geforceerde installatie een directe, duidelijke runtimefout. Hostpreflight,
installers, ontwikkelinstellingen en actuele documentatie volgen dat contract.
