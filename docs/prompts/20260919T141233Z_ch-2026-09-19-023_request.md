# Verzoek CH-2026-09-19-023

De eigenaar vraagt een expliciete E2E-integratietest in de CI-flow, met een
gemockte KVK-check.

De huidige kwaliteitsgate draaide al synthetische E2E-unit-/integratietests,
maar de workflow benoemde geen afzonderlijke E2E-poort. Voeg een herkenbare,
offline proef toe die van een lege run via bronvoorbereiding, KVK-verwerking,
filters, export en audit loopt, en maak die op zowel macOS als Windows een
expliciete CI-stap. Geen live bron- of KVK-aanroepen.

Requirementrelaties: CH-E2E-001/002/003, CH-KVK-003, CH-TEST-001/002 en
CH-GOV-001. Versie-impact: test-/CI-wijziging in de nog niet gepubliceerde
1.1.1-broncode; geen nieuwe release of wijziging van v1.0.0.
