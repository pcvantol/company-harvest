# Verzoek CH-2026-09-19-042

**Datum:** 19 september 2026
**Gebruikersvraag:** "Bouw een functie in cli in dat je tot kvk check kunt uitvoeren met 1 commando"

Interpretatie: voeg een enkel CLI-commando toe dat op een kale machine een nieuwe HARVEST-run kan starten, de gebonden bronnen downloadt en verwerkt, de gededupliceerde master en pre-KVK-filter uitvoert en stopt vóór iedere KVK-aanroep. Een bestaande run moet met hetzelfde commando hervatbaar zijn. Geen productieharvest of release is gevraagd.

Relaties: CH-PREKVK-001 t/m CH-PREKVK-010, CH-E2E-001; nieuw CH-PREKVK-011. Bestaande bron- en filtercontracten blijven leidend.
