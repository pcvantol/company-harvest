# Opdracht CH-2026-09-19-029

Ontvangen 2026-09-19: "verwijder alle < 2.0 tags en releases".

Scope: verwijder uitsluitend Git-tags en GitHub Release-objecten waarvan de
SemVer-versie strikt lager is dan 2.0.0. Laat broncommits, overige tags,
actuele release `v2.0.0`, lokale rungegevens en historische documentatie
intact. Controleer vóór en na de verwijdering de werkelijke lokale en remote
tags en alle GitHub Releases, inclusief eventuele concepten.

Bij ontvangst: lokale en remote tags `v1.0.0` en `v2.0.0`; gepubliceerde
GitHub Releases `v1.0.0` en `v2.0.0`. Er zijn geen andere versies onder 2.0
gevonden. Exact doel is dus uitsluitend `v1.0.0` (release met assets en
lokale/remote geannoteerde tag). De historische `v0.1.0`-release en -tag
waren al eerder verwijderd.

Requirementrelaties: CH-TEST-002 en CH-DIST-002. Versie-impact:
pakketversie en v2.0.0-bytes blijven 2.0.0;
v1.0.0 is na uitvoering niet meer publiek installeerbaar via GitHub Release.
