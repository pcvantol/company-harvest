# Verzoek CH-2026-09-19-020

- Datum: 2026-09-19
- Eigenaar: gebruiker
- Versie-impact: nieuwe CLI-capability; nieuwe releaseversie vereist vóór publicatie

## Verbatim verzoek

> nu zijn alle stappen los uitvoerbaar in de cli, voeg een geintegreerd commando toe waarin je het proces e2e kunt uitvoeren, dus op kale machine. vanaf bron download, door de kvk check heen, tot definitieve eindlijst
> voeg, om dit te kunnen testen, een harde --limit-kvk-check parameter toe, waarmee je de kvk check stap kunt beperken tot bijv 50 items (waardoor het eindresultaat dus maximaal 50 items bevat!!)

## Interpretatie en grens

Een expliciet gestart geïntegreerd commando moet de bestaande, installeerbare
wheelketen zonder checkout doorlopen. Een begrensde test verwerkt een duurzaam
vastgelegde cohort van hoogstens N KVK-kandidaten uit de volledig voorbereide
bronlijst. De uiteindelijke lijst telt hoogstens N unieke KVK-nummers en is
expliciet partieel ten opzichte van de volledige kandidatenpopulatie. Herstart
van dezelfde run mag de cohort of grens niet vergroten. Geen live bulkmeting of
nieuwe KVK-run tegen de eerder geblokkeerde lokale run als implementatietest.
